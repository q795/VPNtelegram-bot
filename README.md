# VPN Telegram Bot - VLESS Demo

Телеграм-бот для раздачи VPN-подписок на протоколе VLESS (демо-режим).

## Возможности

- 📋 Профиль пользователя с информацией о подписке
- 🧪 Бесплатный пробный период
- 💳 Покупка подписок (демо-оплата)
- 📱 Генерация QR-кодов
- 📥 Скачивание конфигов
- 🖥 Выбор сервера
- 📊 Статистика

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Настройте токен бота в `.env`:
```env
BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN
```

3. Запустите бота:
```bash
python main.py
```

## Структура проекта

## Команды бота

- `/start` - Запуск бота
- `/menu` - Главное меню
- `/stats` - Статистика (для админа)

## Демо-режим

В демо-режиме бот работает без реального VPN-сервера:
- Генерируются тестовые VLESS-конфиги
- Оплата имитируется
- Трафик учитывается демо-значениями

## Переход на продакшен

Для работы с реальным VPN:
1. Арендуйте VPS-сервер
2. Установите 3x-ui или Xray
3. Подключите бота к панели управления
4. Настройте реальные серверы в `config.py`
5. Интегрируйте платёжную систему (ЮKassa, Telegram Stars)
